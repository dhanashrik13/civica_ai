API Documentation

Integrate with CivicPulse's civic infrastructure.

Getting Started

The CivicPulse API allows developers to programmatically report issues and retrieve status updates. Our REST API is built on Django REST Framework and returns JSON data.

Core Endpoints

Method Endpoint Description
GET /api/v1/issues/ List all public civic issues.
POST /api/v1/report/ Report a new civic issue.
GET /api/v1/issues/{id}/ Retrieve detailed status of an issue.

Sample Request

POST /api/v1/report/
Content-Type: application/json
Authorization: Token your_api_token

{
    "title": "Broken Streetlight",
    "description": "The streetlight at 5th Ave is not working.",
    "latitude": 40.7128,
    "longitude": -74.0060,
    "category": "electricity"
}

Sample Response

{
    "status": "success",
    "issue_id": "12345",
    "message": "Report received and routed to Electricity Department.",
    "estimated_resolution": "2026-04-16T10:00:00Z"
}
