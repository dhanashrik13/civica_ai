# 🚀 Civica AI
### AI-Powered Civic Problem Reporting & Intelligent Governance Platform

Civica AI is an intelligent civic issue reporting and management platform developed using **Django**, **Artificial Intelligence**, and **Machine Learning**. It enables citizens to report public issues while automatically categorizing complaints, assigning them to the appropriate departments, and assisting administrators through AI-driven insights.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/dhanashrik13/civica_ai.git
```

```bash
cd civica_ai
```

---

## Create Virtual Environment

### Windows

```bash
python -m venv venv
```

Activate

```bash
venv\Scripts\activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Configure Environment Variables

Create a `.env` file in the project root.

Example:

```env
SECRET_KEY=your_secret_key

DEBUG=True

DATABASE_URL=sqlite:///db.sqlite3

GEMINI_API_KEY=your_api_key

OPENAI_API_KEY=your_api_key
```

---

## Apply Migrations

```bash
python manage.py migrate
```

---

## Run Server

```bash
python manage.py runserver
```

Open

```
http://127.0.0.1:8000/
```
